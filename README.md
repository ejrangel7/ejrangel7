## Featured project

### [Retail Operations Dashboard](https://github.com/ejrangel7/retail-operations-dashboard)

A production-deployed full-stack dashboard for monitoring retail revenue, orders, inventory, low-stock alerts, fulfillment activity, and downloadable CSV reports.

- React and TypeScript frontend with responsive operational reporting
- Node.js and Express API with authentication, authorization, and rate limiting
- PostgreSQL migrations, data-integrity constraints, and least-privilege runtime access
- Docker and Docker Compose development environments
- Vitest, Testing Library, and Playwright automated testing
- ESLint, type checking, coverage thresholds, and GitHub Actions CI
- Render and Neon production deployment
